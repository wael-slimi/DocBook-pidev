# DocBook – Medical Record Management System

## Overview
This project was developed as part of the PIDEV – 3rd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2025–2026). 

DocBook is a full-stack web application designed to digitize medical interactions. It allows patients to initialize secure medical dossiers, upload clinical documents, and search for specialized doctors, while providing healthcare providers with a streamlined way to manage patient history.

## Features
- **Medical Dossier Management:** Secure setup and persistence of patient health records.
- **Clinical Repository:** A dedicated space for uploading and viewing medical documents (PDFs, images).
- **Advanced Doctor Search:** Filter specialists by field, price range, and availability.
- **Dynamic Dashboard:** Real-time statistics and quick access to the latest medical records.
- **Role-Based Security:** Distinct interfaces and permissions for Patients and Doctors.

## Tech Stack
### Frontend
- **Twig:** Template engine for dynamic UI rendering.
- **Tailwind CSS / Flowbite:** Modern styling and component library.
- **JavaScript:** Client-side interactivity.

### Backend
- **PHP 8.2+**
- **Symfony Framework:** Robust MVC architecture.
- **Doctrine ORM:** Database abstraction and management.
- **MySQL:** Relational database for persistent storage.

## Architecture
The application follows the Model-View-Controller (MVC) design pattern, ensuring high maintainability and scalability as required by industrial standards.
